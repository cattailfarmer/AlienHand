# Burger Blaster

Turbo Pascal arcade game ported to the `AlienHand` toolkit.

## Standalone Build

```powershell
cmake -S . -B build
cmake --build build --config Release
```

## Run

```powershell
.\build\Release\BurgerBlaster.exe
```

## Controls

- `Escape`: open the AlienHand menu.
- `Enter`: select menu item or restart after game over.
- `Arrow keys`: move/configure.
- `Space`: fire.
